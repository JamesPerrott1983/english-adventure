Lessons

📦 Publish to the app

Edits you make here live only in this browser. When you have approved your lessons, download the publish file and replace js/custom-lessons.js in the app folder with it. Your approved versions then overwrite the built-in lessons for every computer that runs that copy of the app.

Images

Your picture folder for lessons. Add PNG, JPG, GIF, WebP or SVG files (under 500 KB each). Every picture gets a reference like img:dog-x4k2 that you can use in any lesson's "image" or "thumbnail" field.

Pictures are stored in this browser on this device. To use the same pictures on another computer, copy the files into assets/lesson-images/ on the server and reference them by path instead (e.g. "assets/lesson-images/dog.png").

Image storage (IndexedDB) is not available in this browser.

Edit a lesson (JSON)

Pick a picture for an answer

Click inside the JSON exactly where the picture reference belongs (between the quotes of an "image" value), then click a picture below — its reference is inserted at the cursor.

Import a lesson

Choose a lesson JSON file. It is validated before it appears in the Lesson Library.
